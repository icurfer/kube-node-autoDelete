# 협업 스타일

본 저장소는 1인 운영 프로젝트다. 따라서 다음 스타일을 일관되게 적용한다.

## 응답 톤

- 한국어로 소통. 답변은 짧고 핵심만. 긴 요약·반복 narration 비선호.
- 옵션 제시는 표/번호로 짧게 — 빠른 선택을 위해.
- 매 단계 verbose log 보고 X. 작업 결과는 결정 직후 1-2줄로 요약.

## 짧은 응답의 의미

"응 그렇게 해", "차례대로 진행해라", "배포해라" 같은 **짧은 응답은 직전에 제시한 계획·단계를 모두 승인한다는 의미**다. commit / push / helm install / 클러스터 변경까지 포함한 시퀀스 전체 인가로 해석한다.

새로운 destructive 동작이 끼어드는 경우에만 별도 확인을 받는다.

## 질문의 의미

"왜 ~하지?" 류 질문은 화내는 게 아니라 **이유 / 의도 설명을 요청**하는 것이다. 변명이나 사과 대신 짧고 정확한 이유로 답한다.
